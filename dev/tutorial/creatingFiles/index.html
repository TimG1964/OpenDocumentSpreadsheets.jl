Creating and editing files

A new file

newods makes a file with one sheet, named as you choose. addsheet! adds more:

using OpenDocumentSpreadsheets

xf = newods("Plan")
plan = xf["Plan"]
plan["A1"] = "Task"; plan["B1"] = "Days"
plan["A2:B4"] = ["Design" 5; "Build" 12; "Test" 4]
setFormula(plan, "B5"; val = "=SUM(B2:B4)")

memo = addsheet!(xf, "Notes")
memo["A1"] = "Estimates agreed on 18 November."
writeods("plan.ods", xf; overwrite = true)

<!– shot: creatingnew cells=4x6 –> ![A sheet named Plan with Task and Days in row 1, three tasks with their days below, and their total, 21, in B5](../images/creatingnew.png)

A sheet is addressed by name or by position (xf["Plan"], xf[1]), and sheetnames lists them in order.

Opening a file

ToUse
read a filereadods(path), or openods(path), which is the same
read and edit a fileopenods(path; mode="rw"); save with saveods or writeods
start a new, empty filenewods, or openods(path; mode="w")

With the do-block form of openods, a file opened for writing is saved when the block ends (but not if the block throws). This edits the plan.ods made above:

openods("plan.ods"; mode = "rw") do xf
    xf["Plan"]["B3"] = 14                    # Build takes longer
end

Without it, save explicitly:

xf = openods("plan.ods"; mode = "rw")
xf["Plan"]["B4"] = 5
saveods(xf)                                       # back to plan.ods
writeods("plan-copy.ods", xf; overwrite = true)   # or to another file

Writing a table

writetable writes any Tables.jl source (a DataFrame, a named tuple of vectors, …) with its column names as a header row. writetable! writes one into a sheet of an open file:

people = (Name = ["Ann", "Bob"], Team = ["North", "South"])
notes = (Note = ["Teams agreed on 18 November."],)

writetable("people.ods", people; sheetname = "People", overwrite = true)
writetable("all.ods", "People" => people, "Notes" => notes; overwrite = true)   # several sheets

xf = openods("plan.ods"; mode = "rw")
writetable!(addsheet!(xf, "People"), people; anchor_cell = "B2")
saveods(xf)

Editing keeps the rest of the file

OpenDocumentSpreadsheets doesn't rebuild a file it edits. It copies the original and rewrites only the rows that hold edited or formatted cells, and the columns whose formats changed:

  • untouched sheets, settings, pictures, charts and the other parts stay byte for byte;
  • styles are only added: new automatic styles go into the sheet's content and named styles into the file's styles, and styles it made that no cell uses any more aren't written;
  • in an edited row, the cells you didn't change keep their formatting, notes and links.

A file saved without edits is identical to the original. So a file made in LibreOffice, with features this package doesn't know about, can be edited safely.
